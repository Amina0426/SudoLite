# SudoLite

*SudoLite* is a Progressive Web App (PWA) that lets you solve Sudoku puzzles in your browser — fast, simple, and offline-capable.

## Features

- *Intuitive grid interface* to enter Sudoku puzzles
- *One-click Solve* button using backtracking algorithm
- *Error checking* after submission (not while typing)
- *Hint feature* for when you're stuck
- *Play mode* with score tracking and local storage
- *Responsive & mobile-friendly* design
- *Offline support* via service worker

## Tech Stack

- *HTML, **CSS, **JavaScript*
- *LocalStorage* for saving progress and scores
- *PWA features* (manifest + service worker)

## How to Use

1. Open the app (or install it as a PWA).
2. Enter a Sudoku puzzle in the grid.
3. Click *Submit* to check for errors.
4. Click *Solve* to auto-complete the puzzle.
5. In *Play mode*, solve puzzles manually and track your score.

## Installation (PWA)

- On desktop or mobile, click *"Install"* or use browser menu > Add to Home Screen.
- Once installed, you can use the app offline.
